# course-management-backend-mern

I this repository I have developed a Course Management System Backend API's using Express.js and MongoDB.

Users can register, log in, and manage courses.
Only authenticated users can create, update, delete, or view courses.

You must maintain a proper Express.js folder structure (like in your previous projects: controllers, models, routes, etc.).

Requirements:

1. User Registration API - Fields: name, email, password, phoneNumber.

2. User Login API - Use JWT + cookie for authentication.

3. Get Logged-in User Profile API

4. Update Profile API

5. Create Course API - Fields: title, description, price, duration, category, instructorName, courseImage.

6. Read All Courses API

7. Read Single Course API by ID

8. Update Course API by ID

9. Delete Course API by ID
